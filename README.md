# 🛒 Tokopedia UI Clone - Flutter

A mobile application built with **Flutter** that replicates the user interface (UI) of the **Tokopedia** app. This project focuses on cloning the modern Home Screen layout with dynamic UI components.

## ✨ Features & UI Components

- **Custom Top Bar:** Search bar, notification badge icon, shopping cart, and options menu.
- **Location & Wallet Header:** Delivery address status, wallet balance, and membership tier.
- **Promo Carousel / Banner:** Interactive promotional banners in the main feed.
- **Grid Categories / Quick Menu:** Quick action icons for promos, financial services, and top categories.
- **Horizontal Category Tabs:** Scrollable category filter tabs (All, Electronics, Furniture, Action Figures, etc.).
- **Product Card Grid:** Responsive product cards featuring discount badges, free shipping labels, price tags, and ratings.
- **Bottom Navigation Bar:** Core app navigation (Home, Feed, Orders, Chat, Account).

## 🚀 Getting Started

Follow these instructions to set up and run the project locally:

### Prerequisites

Ensure you have the following installed:
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (latest stable release recommended)
- [Android Studio](https://developer.android.com/studio) / [VS Code](https://code.visualstudio.com/)
- Android Emulator / iOS Simulator / Physical Device

### Installation & Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/tokopedia-ui-flutter.git
   cd tokopedia-ui-flutter
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the application**
   ```bash
   flutter run
   ```
